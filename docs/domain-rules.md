# 领域边界与裁定规则

管理曲艺评奖的作品档案、人员资格、轮次封存、评委回避、匿名评分、现场终评、名额兼得、公示申诉与获奖追溯。

现有领域资料围绕以下边界组织：

- 作品与人员谱系
- 分阶段晋级与封存
- 资格复核
- 评委回避与匿名评分
- 终评场次与现场事实
- 奖项名额与兼得规则
- 公示申诉与确认
- 获奖结果全链追溯

资料版本只能递增。参与方、事实和约束均不能为空，示例不得包含真实个人信息、账号或凭据。

## 参与方与权限

| 角色 | 能做 | 不能做 |
| --- | --- | --- |
| 报送院团 | 报送节目、提交本单位人员材料、补交证明 | 不能确认疑似重复关联、不能查看盲评身份 |
| 参评作者/演员 | 作出原创与首演声明、提出申诉 | 不能修改已封存材料 |
| 评委 | 在回避完成后评分、书面记录评分依据 | 与本人存在作品/人员/单位关系的候选不得分；不得接触分配前的身份核对结果以外的身份信息 |
| 秘书处 | 材料完整性检查、匿名编目、排程 | 不能揭示匿名编号背后的身份、不能确认重复关联 |
| 监审/资格复核组 | 确认疑似重复关联、资格复核裁定、揭示盲评身份、回避裁定 | 不参与评分 |
| 评奖组委会 | 封存轮次、发布公示、确认获奖结果 | 封存后不得改写原轮次结论 |

## 作品档案

- 每个作品保存：曲种、文本沿革链（来源作品、改编关系）、首演事实、原创声明、作者与权利人。
- 改名再报送生成新的**作品版本**，版本挂在同一作品线下；文本指纹相同或相近只产生**疑似重复线索**。
- 疑似重复关联只能由授权人员（监审/资格复核组）确认；仅依据名称相似度的自动合并不允许发生，线索在确认前不影响任何候选的流程。
- 原创声明、首演事实、权利人信息各自带证据与作出时间；声明与证据可以被申诉质疑，质疑期间证据锁定。

## 人员档案

每名参评人员保存：

- 演职关系：在每个节目版本中担任的曲种角色（创作、表演、伴奏等）及参演院团；一名演员可随不同院团参演不同版本，关系按版本记录，不做唯一归属推断。
- 所属单位：按生效区间记录，调动以新区间表示，不覆盖历史。
- 年龄证明：证据与核验日期；新人奖以**报送截止日**年龄判定，证明后补进入资格复核，不回溯改写初评。
- 赛区经历：在哪个分赛区、随哪个版本、结果如何。
- 历史获奖限制：既往获奖记录与对应的本届受限奖项（如表演奖、新人奖的往届获奖者限制）。

文学奖、表演奖、新人奖引用不同的资格事实：文学奖看作者/原创与文本沿革，表演奖看演职关系与现场表演事实，新人奖看年龄证明与历史获奖限制。任一事实缺失或被锁定未决，对应奖项的资格结论不得为"通过"。

## 轮次封存与资格复核

- 初评结束、各分赛区比赛结束时，组委会封存该轮次的**材料指纹集**与**晋级结论**；封存记录不可变。
- 封存之后到达的任何证明只能进入**资格复核案件**；复核结论可调整后续轮次资格，但不改写、不覆盖原轮次的封存记录与结论。
- 复核案件记录：证据、所涉奖项、裁定（通过/不通过/维持）、裁定人与时间，并与原始封存条目建立引用，供追溯。

## 评委回避与匿名评分

- 评委分配前按三类关系计算冲突并产生**回避记录**：
  1. 作品关系：评委是该作品（含沿革链上各版本）的作者、权利人、表演者或编曲；
  2. 人员关系：与候选主创/主演存在亲属、师承等声明关系；
  3. 单位关系：评委与候选报送/参演单位存在在册任职关系。
- 每条回避写明候选、关系类型、依据事实；被回避评委对该候选的评分一律拒绝录入。
- 评分只以**匿名编号**提交。秘书处负责材料完整性与匿名编目，调用任何查询都不能由匿名编号反查出身份；只有监审在评分封闭后可以揭示映射。
- 匿名映射与评分分开保存；秘书处角色下的身份揭示请求直接拒绝。

## 现场终评

- 终评中发生的换角、中止、重新表演均作为**现场事件**登记，挂在节目版本上：
  - 换角：登记更替人员；被替演员失去该候选的表演奖资格，替演人员需具备有效资格（年龄、历史获奖限制等）方取得计分资格；
  - 中止：该次表演不计分，候选进入待决；
  - 重新表演：登记为新的表演尝试并计分，原尝试版本仍保留可查看，不被覆盖。
- 现场事件影响对应候选资格与计分基准，但任何既往版本、评分记录都只能追加、不能删除或改写。

## 名额与兼得

公示前，作品类奖项（节目奖、文学奖）与个人类奖项（表演奖、新人奖）**分别**校验：

- 名额：每奖项获奖数不得超过配额；
- 兼得：按当届规则校验同一作品/同一人可否兼得（如同一人不同时获表演奖与新人奖、节目奖与文学奖的兼得限制）。

任一校验未通过，公示不得发布；校验结论留痕，可追溯到具体候选与规则。

## 公示与申诉

- 公示按自然日计算截止时间。公示期内系统停机的，公示截止时间按**与公示期重叠的停机时长**顺延，剩余期限不得被缩短；停机若完全处于公示期之外则不顺延。
- 申诉针对具体目标（资格、文本、评分）提交；受理后锁定对应证据，被锁定的候选/奖项暂停确认。
- 锁定范围最小化：无关奖项、无关候选不受影响，照常确认。
- 申诉裁定（支持/驳回）写明改变了什么：资格结论、关联关系或评分；支持的裁定通过资格复核或勘误通道产生新版本事实，原始记录保留。

## 获奖追溯

从任一获奖结果必须能够追到：

1. 作品沿革：作品线下的全部版本、改名再报送、重复关联确认人；
2. 人员资格：演职关系、所属单位区间、年龄证明、赛区经历、历史获奖限制，及资格复核案件；
3. 轮次封存：初评与分赛区封存指纹、晋级结论；
4. 评委回避：哪位评委因哪条关系回避了该候选；
5. 评分：匿名评分、封闭后的身份揭示、现场事件对计分的影响；
6. 申诉：哪个申诉改变了哪项裁定，以及改变前后的结论。

追溯报告只汇聚已存在的记录，不做推断；缺少的环节明确显示为缺口。
