# 曲艺评奖作品谱系与现场终评

管理曲艺作品版本、分赛区晋级、终评排程、评委回避和奖项申诉。

## 参与方与事实

主要参与方包括参评作者与演员、报送院团、赛区工作人员、评委、评奖组委会。领域资料记录以下已经确认的事实：

- 本届曲艺牡丹奖收到四百三十四个参评节目
- 评选经过初评、四个分赛区比赛和八场现场终评
- 奖项分为节目奖、表演奖、文学奖和新人奖并覆盖四十八个曲种

## 业务约束

- 作品版本
- 参评资格
- 评委回避
- 现场排程
- 奖项名额
- 公示申诉

`contracts/context.schema.json` 描述资料结构，`fixtures/context.json` 提供不含真实身份信息的示例，`src/award_context.py` 负责读取和校验这些资料。

## 开发命令

运行测试：

```bash
python3 -m unittest discover -s tests -v
```

编译检查：

```bash
python3 -m compileall -q src
```

两条命令只读取仓库内文件，不需要连接外部业务系统。
